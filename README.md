# Blookahoot

A combined Kahoot + Blooket style quiz game platform with new and exciting game modes.

## Features
- Quiz creation
- Live join with PIN (demo)
- Classic Kahoot-style timed quiz
- New modes: Treasure Quest, Alien Defense, Factory Frenzy, Space Race
- Built with Next.js for easy Vercel deployment

## Game Modes
- **Classic**: Standard real-time quiz leaderboard
- **Treasure Quest**: Answer to dig treasures, risk traps
- **Alien Defense**: Power defenses with correct answers
- **Factory Frenzy**: Resource management based on quiz performance
- **Space Race**: Competitive racing with boosts from accuracy

## Development
This is an MVP scaffold. Next steps: integrate Socket.io or Supabase Realtime for true multiplayer, add persistent storage, more polished game visuals and mechanics, user accounts.

Deployed on Vercel.
